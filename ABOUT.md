## 💡 What is CRM Solution?

**CRM Solution** is an ambitious experiment in building a comprehensive, enterprise-grade Customer Relationship Management platform using modern "vibe coding" techniques and AI-assisted development. It explores cutting-edge technologies and architectural best practices, offering the flexibility to deploy as a **traditional monolith** for simplicity or scale horizontally with a **microservices architecture** for enterprise demands.

This isn't just another CRM—it's a **full-stack innovation experiment** that demonstrates how far modern development practices, AI assistance, cloud-native patterns, and rapid prototyping can take an enterprise application **from concept to functional system**.

## 🎯 Why CRM Solution?

### **Flexible Architecture That Grows With You**

Choose your deployment strategy based on your needs:

- 🏢 **Monolithic Mode** - Perfect for startups and small teams. Deploy everything in minutes with a single container.
- 🌐 **Microservices Mode** - Scale independently with 8 specialized services, each optimized for its domain.
- 🔄 **Seamless Migration** - Start simple, scale when needed—no major rewrites required.

### **Enterprise Features, Startup Agility**

We've packed enterprise-grade capabilities without the enterprise-grade complexity:

- **Multi-tenant Architecture** - Support multiple organizations with data isolation
- **Real-time Collaboration** - SignalR-powered live updates and concurrent editing
- **AI-Powered Intelligence** - Integrated LLM support (OpenAI, Anthropic, and more)
- **Advanced Deduplication** - Fuzzy matching with Levenshtein and Soundex algorithms
- **Comprehensive Workflow Engine** - Visual designer with conditional logic and approval flows
- **Multi-Database Support** - MariaDB, PostgreSQL, SQL Server—your choice

## 🚀 Quick Start

Get up and running in under 5 minutes:

```bash
# Clone the repository
git clone https://github.com/alal76/crm-solution.git
cd crm-solution

# Start everything with Docker
docker compose -f docker/docker-compose.yml up -d

# Access the application
# Frontend: http://localhost
# API:      http://localhost:5000
# Swagger:  http://localhost:5000/swagger
```

**Initial Setup:** On first run, the system will seed a default admin account. See the [README](README.md#default-login-credentials) for initial login details.
